# WDCC Flagship Storefront

Owner-controlled production storefront for We Don't Care Cars. The repository contains every public page, the five active inventory records, and the dealership-uploaded vehicle photos required to deploy the site independently.

`/dealer` redirects to the separate live dealer portal at `https://dealer.wedontcarecars.com`; this storefront does not ship a simulated admin dashboard.

## Commands

- `npm install` installs dependencies.
- `npm run dev` starts local development.
- `npm run build` creates the production build.
- `npm start` serves the production build.

The canonical production domain is `https://wedontcarecars.com`.
